# 🎬 QA Buscador de Filmes

Repositório de documentação de testes manuais para o projeto
[Buscador de Filmes](https://gabriellesca.github.io/buscador-filmes),
uma aplicação frontend que consome a API do TMDB.

---

## 🎯 Objetivo

Praticar e documentar testes manuais com casos de teste estruturados,
resultados de execução e relatórios de bugs, simulando o trabalho
de uma QA Analyst em um projeto real.

---
